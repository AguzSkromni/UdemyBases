# PreProyecto: etapas de desarrollo

Cada etapa termina con un entregable comprobable. No avanzas si el entregable falla.

## Etapa 1: Entorno
**Conceptos a revisar:** Unity Hub, plantillas, Git, `.gitignore` de Unity, VS Code conectado a Unity.
**Entregable:** proyecto 2D creado y primer commit en Git.
- [ ] Hecho

## Etapa 2: Editor
**Conceptos a revisar:** Hierarchy, Inspector, Project, Transform, GameObject, Prefab básico, Play mode.
**Entregable:** escena con suelo, cubo y cámara.
- [ ] Hecho

## Etapa 3: MonoBehaviour
**Conceptos a revisar:** `MonoBehaviour`, `Start`, `Update`, `FixedUpdate` (cuándo usar cada uno), `[SerializeField]`.
**Entregable:** script que imprime un mensaje en consola al iniciar.
- [ ] Hecho

## Etapa 4: Física 2D
**Conceptos a revisar:** `Rigidbody2D`, `Collider2D`, colisión vs trigger, Layers y matriz de colisiones.
**Entregable:** cubo que cae y se detiene sobre el suelo.
- [ ] Hecho

## Etapa 5: Input System
**Conceptos a revisar:** Input Actions (acciones, bindings, mapas), lectura de movimiento y salto, diferencia con el input viejo.
**Entregable:** cubo que se mueve y salta con teclado y con mando.
- [ ] Hecho

## Etapa 6: Instanciar y destruir
**Conceptos a revisar:** `Instantiate`, `Destroy`, prefabs, límites de pantalla.
**Entregable:** genera esferas cada X segundos y las destruye al salir de pantalla.
- [ ] Hecho

## Etapa 7: Datos y UI
**Conceptos a revisar:** ScriptableObject (crear y leer), TextMeshPro, Canvas.
**Entregable:** contador en pantalla con su valor inicial leído de un ScriptableObject.
- [ ] Hecho

## Etapa 8: Escenas y build
**Conceptos a revisar:** `SceneManager.LoadScene`, reinicio de escena, Build Settings, build para PC.
**Entregable:** ejecutable de PC que corre y se controla con mando.
- [ ] Hecho
