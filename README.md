# UdemyBases

Repositorio con los proyectos base del curso de desarrollo de videojuegos en Unity con C#.

## Estructura

UdemyBases/
└── Bases/
├── PreProyecto/
├── Proyecto1/
└── ...


Cada carpeta dentro de `Bases/` es un proyecto de Unity independiente.

## Qué contiene el repo

- Scripts C# (`Assets/`)
- Escenas y prefabs
- Configuración del proyecto (`ProjectSettings/`, `Packages/`)
- Archivos `.meta` (necesarios para las referencias entre assets)

## Qué no contiene

- Carpetas generadas por Unity (`Library/`, `Temp/`, `Obj/`, `Build/`, `Logs/`)
- Binarios pesados (modelos, audio, video, builds)

## Cómo abrir un proyecto

1. Clona el repo.
2. Abre Unity Hub y añade la carpeta del proyecto dentro de `Bases/`.
3. Usa la versión de Unity indicada en `ProjectSettings/ProjectVersion.txt`.
